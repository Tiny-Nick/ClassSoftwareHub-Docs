# Windows 10 优化指南

这篇指南讲 Windows 10 上真正有效的优化手段。它与 Windows 11 那篇是配套的：思路相同，但路径、可用的开关、以及一个大前提都不一样。

**大前提是：Windows 10 已经在 2025 年 10 月 14 日停止支持。** 版本 22H2 是最后一个版本，之后不再有功能更新，常规安全更新也已停止。这件事决定了优化的目标：从「让系统更好用」变成「让一台不再有新补丁的设备尽可能稳定、可用、风险可控」。

本文适用于 Windows 10 22H2（内部版本 19045）。更早的版本（1809、1903 等）大部分设置位置一致，但部分功能不存在，文中会注明。

## 一、先看清前提：这台机器还要不要继续用

在动任何设置之前，先弄清这台设备的处境，否则优化就是无意义的整理。

### 停止支持意味着什么

| 项   | 状态  |
| --- | --- |
| 功能更新 | 已停止，22H2 是终点 |
| 常规安全更新 | 已于 2025 年 10 月 14 日停止 |
| 消费者版扩展安全更新（ESU） | 2025 年 10 月至 2026 年 10 月 13 日，现已结束 |
| 企业版 / 教育版 ESU | 最多可延至 2028 年，需要另行购买 |
| LTSC 2021 | 支持到 2027 年 1 月 12 日；IoT Enterprise LTSC 2021 到 2032 年 |
| 技术支持 | 已停止 |

消费者版 ESU 当时有三种取得方式：同步系统设置免费、兑换积分、或一次性付费，一份许可最多可用于十台设备。它只提供「关键」与「重要」级别的安全更新，不含功能改进，也不含技术支持。现在这一窗口也已关闭。

也就是说：**一台普通的 Windows 10 家用或教室设备，此刻已经拿不到任何新的安全补丁。**

### 三种现实选择

1. **升级到 Windows 11**。硬件满足要求（第八代以上处理器、TPM 2.0、UEFI 安全启动、4 GB 内存、64 GB 存储）时这是最优解。教室设备多数是整机采购，能否升级要看 OPS 模块的型号，不要仅凭处理器代次判断。
2. **换一台设备**。硬件不满足要求时，升级是折腾，换机是务实。
3. **继续使用，但改变用法**。这是很多教室的现实选择：设备还能跑，换不起，也不值得为它升级。这种情况下，优化的目标变成「降低暴露面」，具体做法在第十节。

### 判断风险等级

不是所有 Windows 10 设备的风险都一样。按这四条自评：

* 是否接入互联网（尤其是能访问外网）。
* 是否经常插 U 盘、接收学生交来的文件。
* 是否存放成绩、名单、照片等需要保密的数据。
* 是否承担唯一的教学用途（停了就没法上课）。

四条中占两条以上，就应当优先考虑升级或换机，而不是靠优化续命。

## 二、与 Windows 11 的路径差异

同一件事，两代系统的入口常常不同。这张表可以先存着，后面各节会展开。

| 事项  | Windows 10 | Windows 11 |
| --- | --- | --- |
| 存储设置 | 设置 → 系统 → 存储 | 同   |
| 清理建议 | 无独立入口，用「临时文件」页 | 设置 → 系统 → 存储 → 清理建议 |
| 启动项 | 仅任务管理器（`启动` 页） | 任务管理器，或「设置 → 应用 → 启动」 |
| 应用列表 | 设置 → 应用 → 应用和功能 | 设置 → 应用 → 已安装的应用 |
| 电源模式 | 控制面板 → 电源选项（节能 / 平衡 / 高性能） | 设置 → 系统 → 电源和电池 → 电源模式 |
| 动画效果 | 设置 → 轻松使用 → 显示 → 在 Windows 中显示动画 | 设置 → 辅助功能 → 视觉效果 |
| 透明效果 | 设置 → 个性化 → 颜色 → 透明效果 | 同   |
| 通知  | 设置 → 系统 → 通知和操作 | 设置 → 系统 → 通知 |
| 隐私与诊断 | 设置 → 隐私 | 设置 → 隐私和安全性 |
| 系统更新 | 设置 → 更新和安全 → Windows 更新 | 设置 → Windows 更新 |
| 任务栏资讯 | 有「资讯和兴趣」 | 改为「小组件」 |

## 三、磁盘

### 看清占用

打开设置 → 系统 → 存储，页面上是各分类的占用。点「显示更多类别」看完整分布，其中「系统和保留」这一项经常占得最多，展开能看到系统文件、虚拟内存、休眠、系统还原分别占了多少。

Windows 10 没有 Windows 11 那种「清理建议」页，所以更依赖下面的几个入口。逐层看清目录占用，用本应用内的 [磁盘空间](csh://tool/disk-map)：方块越大占得越多，单击进入下一层。

### 存储感知

路径：设置 → 系统 → 存储，打开「存储感知」。

它是系统自带的定期清理，可配置三项：

* **运行频率**：空间不足时、每天、每周、每月。默认「空间不足时」，教室设备建议改每周。
* **删除回收站中的文件**：默认 30 天。
* **删除下载文件夹中的文件**：默认「从不」，**不要改**。很多人把要留的文件放在下载文件夹。

与 Windows 11 一致，它只清理系统盘，并且需要登录联网一段时间才会运行。教室里长期不关机的设备可以定期手动点一次「立即释放空间」。

### 临时文件

路径：设置 → 系统 → 存储 → 临时文件。

这里可以一次勾选多项，包括「Windows 更新清理」「传递优化文件」「缩略图」「以前的 Windows 安装」，勾完点「删除文件」。这是 Windows 10 腾空间最省事的一处，比磁盘清理界面更直观。

「以前的 Windows 安装」会删掉 `C:\Windows.old`，删了就无法回退到升级前的版本。

### 磁盘清理

开始菜单搜索「磁盘清理」，选中系统盘，点「清理系统文件」，再选一次系统盘。它会重新统计，把「Windows 更新清理」「传递优化文件」列出来，一次常见几个 GB 到十几个 GB。

不建议勾「下载」与「回收站」，这个工具不做二次确认。

### 保留的存储（Windows 10 特有）

Windows 10 从 1903 起有一项「保留的存储」，专门扣下一块空间给更新、临时文件与系统缓存用，通常 7 GB 左右，随安装的语言与可选功能变化。

它的好处是保证更新时有地方写文件；代价是这块空间在资源管理器里看不见，明明没装东西，可用空间却少了一截。

1903 与 1909 只能用注册表方式处理，**不建议**。2004 及之后版本可以用命令查看与关闭：

    Dism.exe /Online /Get-ReservedStorageState
    Dism.exe /Online /Set-ReservedStorageState /State:Disabled

重新开启把 `Disabled` 换成 `Enabled` 即可。

有两点要注意：

* 系统正在安装更新时执行会报「保留存储正在使用中」，等更新装完、重启之后再试，不要强行绕过去。
* 关掉它只是把预留的空间还回来，不会删除系统文件。系统盘紧张时可以先关，装完大更新后再打开。

Windows 11 也有这项功能，但在 Windows 10 上更容易成为「空间对不上」的原因。

### 休眠文件

系统盘根目录的 `hiberfil.sys` 是休眠文件，通常约为内存的 40%，同时支撑休眠、快速启动与混合睡眠三件事。

| 做法  | 命令（管理员命令提示符） | 结果  |
| --- | --- | --- |
| 完全关闭 | `powercfg /h off` | 文件删除，休眠、快速启动、混合睡眠一起失效 |
| 只留快速启动 | `powercfg /h /type reduced` | 文件缩到约内存的 20%，休眠不可用 |
| 恢复默认 | `powercfg /h on` | 重建文件 |

注意 Windows 10 早期版本对 `/type reduced` 支持不一，若命令报参数不正确，先执行 `powercfg /h /size 0` 让系统重新接管大小，再设置类型。

本应用内的 [系统功能](csh://tool/sysfeatures) 把这几项做成了开关，不必记命令。

### 分页文件

`pagefile.sys` **不建议关闭**。它不只承担「内存不够时顶上」，还为程序提供提交内存额度，并承载蓝屏时的崩溃转储。关掉后大内存申请可能失败，蓝屏也拿不到转储。

默认由系统管理大小即可。确实需要挪动时，在 [虚拟内存](csh://tool/pagefile) 里操作：关掉自动管理，选中目标盘，设置自定义大小或无分页文件，点「设置」确认，再重启。

不要设在移动硬盘、U 盘上，也不要设在与系统盘同一块物理硬盘的其他分区，那样没有性能收益。

### 该留多少空间

保留可用空间的 10% 到 15%。低于这个比例，机械硬盘的写入会更慢，功能更新会失败，系统还原与休眠也会失效。

Windows 10 教室设备常见的是 128 GB 甚至 64 GB 的固态盘，这类设备建议把「新内容的保存位置」指向其他盘：设置 → 系统 → 存储 → 更改新内容的保存位置。

## 四、内存与分页

### 内存压缩

Windows 10 从 1809 起有内存压缩，默认开启。它把不活跃的内存页压缩后留在内存里，减少读写硬盘。压缩消耗一点处理器，但比硬盘快得多，不建议关闭。

任务管理器性能页的内存一栏能看到「已压缩」的量，几百 MB 属于正常。

### 判断内存是否够

* 使用率长期在 85% 以上，说明确实吃紧。
* 提交大小远大于物理内存，说明系统已在大量换页。

4 GB 内存运行 Windows 10 属于勉强：系统本身要占 2 GB 左右，剩下一半留给应用。这类设备最有效的手段是加内存，而不是调设置。DDR3 时代的整机加一条 4 GB 内存，成本不高，效果比任何软件优化都明显。

### 看进程

`Ctrl + Shift + Esc` 打开任务管理器，在「进程」页按内存排序，能直接看出谁在吃内存。展开箭头可以看到同一程序的子进程。

本应用内的 [Hub AI](csh://page/hubai) 也能做这件事：打开后展示本机概况，包括内存、进程、启动项与已装软件，并给出初步判断。需要先在 [设置 → Hub AI](csh://settings/hubai) 里配置模型。

## 五、启动项

### 只有一条路：任务管理器

Windows 10 没有「设置 → 应用 → 启动」这一页，管理启动项只在任务管理器里：`Ctrl + Shift + Esc`，切到「启动」页。

这一页会显示名称、发布者、状态与「启动影响」。影响由系统实测得出：

| 等级  | 判定  |
| --- | --- |
| 高   | 启动时占用处理器超过 1 秒，或磁盘读写超过 3 MB |
| 中   | 处理器占用 300 毫秒到 1 秒，或磁盘读写 292 KB 到 3 MB |
| 低   | 处理器占用低于 300 毫秒且磁盘读写低于 292 KB |
| 未测量 | 尚未采集到数据 |

右键选择「禁用」，改动立刻生效。想恢复随时「启用」，与卸载无关。

### 该禁的与该留的

**可以禁用**：软件自动更新程序、游戏平台助手、网盘客户端（不用时）、各类「助手」与「加速器」、播放器后台、聊天软件的开机自启。

**建议保留**：安全软件实时防护、显卡与声卡驱动管理程序、触控板与鼠标驱动、输入法、正在使用的同步工具。

**不确定的**：先看发布者。是 Microsoft 就留着；不是就看名字对不对得上自己装的软件，对不上先别动，右键「搜索在线」查。

### 另外两个来源

* **启动文件夹**：`Win + R` 输入 `shell:startup`（当前用户）或 `shell:common startup`（所有用户），里面快捷方式会在登录后执行。删掉不需要的快捷方式即可。
* **注册表 Run 项**：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 与 `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`。不建议手改，容易留下找不到路径的残项。

### 治本的做法

有些软件在任务管理器里禁用后，更新一次又自己开回来。原因是它只改了系统注册，程序自身的设置没变。进软件自己的设置关掉「开机启动」，才是治本。

### 服务与计划任务

**不建议批量改动。** 确实要动，先勾选「隐藏所有 Microsoft 服务」，只处理明确认得出来的第三方残留服务，把启动类型改为「手动」而不是「禁用」。

认不出用途的一律不动：更新校验、驱动安装、安全启动校验都依赖一批名字陌生的服务，关掉不会立刻出问题，而是在几个月后以「更新失败」的形式还回来。

## 六、电源

### 电源计划

Windows 10 用的是「电源计划」，不是 Windows 11 的「电源模式」。三个内置计划：

* **节能**：压低频率，续航优先。
* **平衡**：默认，按负载动态调整。
* **高性能**：倾向于保持高频率，响应快，发热与耗电上升。

入口：设置 → 系统 → 电源和睡眠 → 其他电源设置，或控制面板 → 硬件和声音 → 电源选项。

教室设备常年插电，日常用平衡即可。需要跑大型课件或触控书写发涩时切到高性能，用完切回。

### 卓越性能（可选）

Windows 10 另有一个默认隐藏的「卓越性能」计划，比高性能更激进地抑制降频。它在台式机、插电场景下有意义，笔记本上会让发热与耗电明显上升。

以管理员身份打开命令提示符或 PowerShell：

    powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61

执行后回到电源选项，会多出「卓越性能」。不想保留时在同一个界面删除该计划即可。

不建议在教室设备上常开：白板设备的散热本就吃紧，长期高温会让处理器更早开始降频，反而更卡。

### 快速启动

Windows 10 的「关机」默认是混合关机：保存内核状态后断电，下次开机从该状态恢复，比完全冷启动快几秒。

代价有三：

* 关机不是真正的完全重启，某些驱动问题、更新未完成的状态会延续到下次开机。
* 双系统环境下会占用分区锁。
* 依赖休眠文件，关掉休眠后它一起失效。

保持默认即可。遇到「改了设置不生效」「驱动装了没反应」这类怪问题时，用「重启」而不是「关机再开」。

## 七、视觉与响应

### 动画

路径：设置 → 轻松使用 → 显示 → 在 Windows 中显示动画。

关闭后窗口最小化、开始菜单弹出变成瞬间完成。老设备上感受明显，代价是界面少了过渡，观感生硬。

同一页还有「显示桌面背景图像」「在 Windows 中显示透明度」等项，可一并按需关闭。

### 透明效果

路径：设置 → 个性化 → 颜色 → 透明效果。

关闭后开始菜单与任务栏失去毛玻璃，能省一点显卡开销，集显设备上有意义。

不建议用注册表去改任务栏透明度：那条键值不在微软公开的配置项里，改动在系统更新后可能失效，也可能造成任务栏渲染异常。

### 资讯和兴趣（教室必关）

Windows 10 任务栏右侧默认有一块天气与资讯。它会在后台拉取内容，教室设备上既是干扰也是负担。

右键任务栏 → 资讯和兴趣 → 关闭。这一项在 Windows 11 上对应「小组件」，两代都可以关掉。

### 通知

路径：设置 → 系统 → 通知和操作。

可以整体关闭，也可以逐个应用关闭。教室设备建议整体关闭，避免上课时弹出更新提示、软件广告、邮件预览。副作用是所有通知都不再出现，包括需要留意的系统提示。

### 任务栏与开始菜单

本应用内的 [系统优化](csh://tool/systemtweaks) 把这类开关集中在一页：任务栏搜索框样式、隐藏任务视图按钮、任务栏按钮合并方式、时钟显示秒、始终显示托盘图标、使用小图标、关闭通知中心、开始菜单不显示推荐建议、关闭商店应用推广等。

其中「隐藏任务栏上的人脉按钮」仅 Windows 10 有效，Windows 11 没有这个按钮。改完点「应用更改」，每项下方都写了副作用。

## 八、隐私

### 诊断数据

路径：设置 → 隐私 → 诊断和反馈。

Windows 10 的诊断数据分「基本」与「完整」两档。选「基本」即可，「完整」会收集更多使用数据。

下面几项可以关闭：

* **改善墨迹书写和键入**：上传手写与输入样本。
* **量身定制的体验**：用诊断数据做个性化建议。
* **查看诊断数据**：仅本机查看，不影响。

### 活动历史

路径：设置 → 隐私 → 活动历史。

「向 Microsoft 发送我的活动历史」可以关闭。这项功能在本机的作用是让时间线知道你在哪些应用里做过什么，教室设备用不上。

### 后台应用

路径：设置 → 隐私 → 后台应用。

可以整体关闭，也可以逐个关。教室设备建议关闭，能减少一批用不到的应用在后台运行。副作用是部分需要后台刷新的应用（例如邮件）不会及时更新。

### 广告 ID

路径：设置 → 隐私 → 常规。

关闭「让应用使用广告 ID」，可以减少基于使用习惯的定向推广。同一页的「让网站访问我的语言列表」「允许 Windows 跟踪应用启动」也可以按需关闭。

## 九、更新

### 现实情况

Windows 10 已经不再提供新的安全更新。「设置 → 更新和安全 → Windows 更新」里不会再出现新的质量更新，除非设备仍在有效的 ESU 或 LTSC 支持期内。

要做的是三件事：

1. **装完最后一批补丁**。检查一次更新，把可用的都装上，让设备停在一个尽可能完整的补丁状态。
2. **不要相信「第三方补丁包」**。打着「Windows 10 继续更新」旗号的第三方补丁来源不明，装上去等于主动开一个后门。
3. **不要用工具强行修改更新通道**，把设备伪装成 LTSC 或企业版来骗取更新，会导致系统状态不一致，后续任何更新都可能失败。

### 如果决定继续用

那就把重点从「打补丁」转向「减少暴露」。具体做法见下一节。

## 十、教室设备的具体做法

这一节针对「短时间内无法升级、也无法换机」的 Windows 10 设备。目标不是让它更安全，而是让风险可控。

### 账号

* **不要用管理员账户日常上课**。为每位教师建标准账户，管理员账户只在装软件时用。
* 每个账户单独建，不要全班共用。共用账户会让软件与设置互相覆盖，出问题分不清是谁改的。

### 网络

* 能不接外网就不接。只连校园内网、只访问内网资源的设备，暴露面小得多。
* 必须联网时，避免在上面登录个人账号、收发邮件、打开陌生链接。

### 移动存储

* 关闭 U 盘自动运行。组策略或注册表都可以设，但更简单的做法是让使用者养成「先杀毒再打开」的习惯。
* 学生交来的文件先在教师机或另一台有防护的设备上过一遍，再拷进教室机。
* 不要为了「方便拷课件」把 U 盘插到公用电脑上再用。

### 数据

* 成绩、名单这类数据不要长期存放在教室机本地。用完拷走或上传到指定位置，本机删除。
* 桌面与文档目录不要开 OneDrive 同步到公共账户，否则所有教室的文件会混在一个账户里。

### 防护

* 保留一个安全软件并保持其病毒库可更新。系统补丁停了，安全软件的库还在更新，这是少数仍在起作用的一层。
* 不要为了省资源把安全软件关掉。真要减少干扰，用排除目录而不是整体关闭。

### 关机与断电

教室设备最常见的数据损失来自直接拉闸。用 [自动关机](csh://tool/autoshutdown) 排一张时间表，到点前保存并关闭；需要立刻断电时先关机再断。

电压不稳的教室建议配一个小容量 UPS。对一台已经停止支持的老设备而言，突然断电造成的系统损坏，恢复起来比新设备更麻烦。

## 十一、做完之后怎么验证

不要凭感觉，用数据对比：

1. **开机时间**：任务管理器 → 启动页，看各程序的启动影响是否下降。Windows 10 没有「上次 BIOS 所用时间」这一行，可以直接用秒表量从按下电源到桌面可用的时间，改前改后各三次取中位。
2. **内存占用**：任务管理器 → 性能 → 内存，看空闲时的占用与已压缩的量。
3. **磁盘空间**：设置 → 系统 → 存储，记录改动前后的可用空间。
4. **稳定性**：改完连续用一周，看是否出现新的卡顿、驱动异常或程序无响应。

出问题的回退顺序：

1. 把那一处改动改回默认。
2. 用之前创建的系统还原点还原（开始菜单搜索「创建还原点」即可创建与还原）。
3. 卸载最近安装的软件或驱动。
4. 恢复上一次的系统镜像（教室设备若做了镜像备份，这一步最快）。

## 十二、常见误区速查

| 做法  | 为什么不该做 |
| --- | --- |
| 关闭分页文件换性能 | 提交内存下降，大程序申请内存会失败；蓝屏拿不到转储 |
| 成批禁用系统服务 | 更新校验、驱动安装依赖这些服务，故障会延后出现 |
| 关闭 Windows Defender | 设备已无系统补丁，这一层更不能撤；应改用排除目录 |
| 用「一键优化」软件 | 删缓存、关服务、清注册表三件事，前一件系统自己会做，后两件留隐患 |
| 注册表清理 | 收益无法测量，误删后系统行为异常难以定位 |
| 内存「释放」工具 | 强行把内存写回分页文件，反而增加磁盘读写 |
| 删除 WinSxS 内容 | 组件存储被破坏，后续任何更新都会失败 |
| 装第三方「续命补丁包」 | 来源不明，等于主动引入后门 |
| 伪装成 LTSC 骗取更新 | 系统状态不一致，更新失败且难以恢复 |
| 常开「卓越性能」计划 | 白板设备散热吃紧，长期高温反而更早降频 |
| 用注册表改任务栏透明度 | 非公开配置项，更新后可能失效或渲染异常 |

## 可以直接用的工具

本应用内与本文对应的入口，Windows 10 与 Windows 11 通用：

* [磁盘空间](csh://tool/disk-map)：方块图看占用，逐层展开。
* [AppData 管理](csh://tool/appdata)：按分类清理用户目录下的缓存。
* [幽灵文件清理](csh://tool/ghostfile)：处理看得见删不掉的残留文件。
* [系统优化](csh://tool/systemtweaks)：任务栏、开始菜单、通知与推荐内容的开关。
* [系统功能](csh://tool/sysfeatures)：休眠、电源计划、内存压缩、长路径、转储。
* [虚拟内存](csh://tool/pagefile)：分页文件的查看与调整。
* [自动关机](csh://tool/autoshutdown)：按天排时间表，到点关机。
* [系统修复](csh://tool/repair)：常见系统问题的修复任务列表。
* [Hub AI](csh://page/hubai)：看清本机的处理器、内存、磁盘、进程与启动项。
