# Windows 11 优化指南

这篇指南讲的是 Windows 11 上真正有效的优化手段：哪些设置改了确实有用，哪些改了只是心理安慰，哪些改完会在几个月后以别的方式还回来。所有操作都走系统自带的界面与工具，不使用第三方「优化大师」类软件。

本文适用于 Windows 11 24H2 及之后的版本。文中提到的设置路径如果与本机略有差异，通常是版本更新的命名调整，功能位置不变。

## 一、先建立正确的预期

### 优化的收益只有三个来源

在 Windows 11 上，能明显感觉到「变快」的改动，基本都落在这三处：

1. **磁盘空间**。系统盘长期低于可用空间的一成，写入会变慢、更新会失败、休眠与还原功能会失效。这是最容易见效也最容易被忽视的一项。
2. **开机自启项**。开机后几分钟内的卡顿，多数来自一批同时启动的程序在抢磁盘与处理器。
3. **电源与显卡策略**。笔记本插电与用电池的表现差别很大，教室设备常年插电，策略选错会白白损失性能或白白发热。

除此之外的改动，包括注册表清理、服务精简、内存「释放」、系统文件「瘦身」，效果要么量不出来，要么代价大于收益。

### 什么情况下优化不管用

* **机械硬盘**。系统装在机械盘上，开机慢、点开软件要等，这是硬件决定的，做完前面三件事也只能改善一点。换固态硬盘的收益远大于任何软件优化。
* **内存不足**。4 GB 内存在 Windows 11 上不够用，开两个浏览器标签就开始换页，任何设置都救不回来。
* **处理器过热降频**。教室设备的 OPS 模块常年积灰，风扇堵住后处理器会主动降频。这种情况先清灰，再谈软件。

判断方法很简单：打开任务管理器，看性能页。磁盘占用长期 100%、内存占用长期 90% 以上、处理器频率被压到基频以下，分别对应上面三种情况。

### 不要做的事

* **不要用一键优化软件**。它们做的事无非是删临时文件、关服务、改注册表，前一件系统自己会做，后两件会留下难以排查的故障。
* **不要成批关闭系统服务**。网上流传的「可禁用服务清单」大多抄自十年前，其中不少服务现在承担更新校验、驱动安装、安全启动校验。关掉之后系统表面正常，直到某次更新失败才发现问题。
* **不要关闭 Windows 安全中心**。教室电脑常年插 U 盘，这是最后一道防线。真觉得它拖慢速度，正确做法是排除指定目录，而不是整个关掉。
* **不要为了省空间删除系统组件**。用工具强行删掉 WinSxS 里的内容，下次功能更新会直接失败。

### 改动的原则

一次只改一处，改完用一段时间再改下一处。每改一处记下改了什么、在哪改的、怎么改回去。出了问题能定位到具体改动，比「全部恢复默认」有用得多。

动手之前建议做一次系统还原点：在开始菜单搜索「创建还原点」，选中系统盘，点「创建」。这一步花一分钟，出问题时能省下重装的时间。

## 二、磁盘：先看清，再动手

### 看清空间去哪了

打开设置 → 系统 → 存储，页面顶部是系统盘的容量条，下面按类别列出占用：已安装的应用、临时文件、文档、图片、其他。点「显示更多类别」可以看到完整分布。

更直观的做法是用方块图逐层展开。本应用内的 [磁盘空间](csh://tool/disk-map) 做的就是这件事：方块越大占得越多，单击进入下一层，单击顶部路径返回。先看清是谁占了空间，再决定动谁，比凭印象删文件靠谱。

有一类情况值得单独说明：系统盘里有一个「其他」分类，往往占得莫名其妙。它通常是虚拟机磁盘、游戏库、以及某些软件写在用户目录下的大文件。用方块图能直接看到具体是哪个目录。

### 存储感知

路径：[设置 → 系统 → 存储](ms-settings:storagesense)，打开「存储感知」开关。

存储感知是系统自带的定期清理。打开后可以在它的设置页里定三件事：

* **运行频率**：磁盘空间不足时、每天、每周、每月。默认是「磁盘空间不足时」，也就是容量条变红才动手。教室设备建议改成每周。
* **回收站保留时间**：默认 30 天，到期自动清空。这个清理是永久的，等同于手动清空回收站。
* **下载文件夹保留时间**：默认「从不」。**不要轻易改这一项**，很多人把重要文件随手放在下载文件夹，被自动删除后找不回来。

它只清理系统盘，其他盘需要单独处理。另外它需要登录且联网超过十分钟才会运行，长期睡眠的设备可能很少触发，这也是建议改成每周、并定期手动点一次「立即运行存储感知」的原因。

### 清理建议

路径：设置 → 系统 → 存储 → 清理建议。

这里按四类列出可清理的内容，比存储感知更细，适合一次性腾空间：

| 类别  | 内容  | 注意  |
| --- | --- | --- |
| 临时文件 | 缓存、日志、旧版系统安装文件 | 勾「以前的 Windows 安装文件」会失去回退上一版本的能力 |
| 大型或未使用文件 | 很久没打开的大文件 | 逐条确认再删 |
| 已同步到云的文件 | 本地副本 | 文件仍在云端，但打开需要联网 |
| 未使用的应用 | 长期没用过的程序 | 有些是偶尔才需要的 |

「临时文件」这一项里还包含「传递优化文件」「Windows 更新清理」「缩略图缓存」，这三类可以放心勾选。

### 清理系统文件

在开始菜单搜索「磁盘清理」，选中系统盘，点「清理系统文件」，再选一次系统盘。这一步会调用系统组件统计更新残留。

值得勾选的是「Windows 更新清理」与「传递优化文件」，前者是安装更新后留下的旧组件，一次下去常见几个 GB 到十几个 GB。其余项按需。

不建议勾选「下载」与「回收站」，除非确认里面没有要留的东西。这个工具不做二次确认，勾了就删。

### 组件存储清理（进阶）

如果做完上面几步空间还是紧，系统更新残留可以在管理员权限的命令提示符里进一步压缩：

    Dism /Online /Cleanup-Image /StartComponentCleanup

加 `/ResetBase` 会压得更彻底，但代价是**已安装的更新无法卸载**：

    Dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase

这一步耗时较长，中途不要关机。教室设备建议在假期做，不要在课前十分钟动。

### Windows.old

做完功能更新（例如从 24H2 升到 25H2）后，系统盘会出现一个 `C:\Windows.old`，体积可能十几 GB。它的作用是让使用者在新版本出问题时回退到旧版本，保留期通常十天。

十天之内可以回退；超过之后系统会自动清理。不建议在文件资源管理器里手动删这个目录，正确做法是通过上面「临时文件」里的「以前的 Windows 安装文件」删除，这样系统记录的状态才一致。

### 休眠文件

系统盘根目录有一个隐藏的 `hiberfil.sys`，大小通常是物理内存的 40% 左右。它同时承担三件事：休眠、快速启动、混合睡眠。

三条处理路径，代价不同：

| 做法  | 命令（管理员命令提示符） | 结果  |
| --- | --- | --- |
| 完全关闭 | `powercfg /h off` | 文件删除，休眠、快速启动、混合睡眠一起失效，普通关机不受影响 |
| 只保留快速启动 | `powercfg /h /type reduced` | 文件缩小到约内存的 20%，休眠不可用，快速启动仍可用 |
| 恢复默认 | `powercfg /h on` | 重新建立文件 |

8 GB 内存的设备，从全量改精简大约能收回 1.5 GB。若确认不需要休眠，直接关掉更省事；但要清楚代价：笔记本合盖断电后不再保存会话，断电时未保存的内容会丢。

本应用内的 [系统功能](csh://tool/sysfeatures) 页面里，休眠与休眠文件两项就在「电源与启动」分组，改完点「应用更改」即可，不用记命令。

### 分页文件

同样在系统盘根目录的 `pagefile.sys` 是分页文件。**不建议关闭**。

它的作用不只是「内存不够时用硬盘顶上」，还包括：为程序提供提交内存（commit），也就是程序申请内存时系统承诺的额度；以及承载蓝屏时写入的崩溃转储。关掉之后，大内存申请可能失败，蓝屏时也拿不到转储文件，排查故障会失去最关键的证据。

默认由系统管理大小，会随内存占用与转储设置自动伸缩。只有在明确知道自己在做什么时才改为固定值，日常使用保持「系统管理的大小」即可。相关开关在 [虚拟内存](csh://tool/pagefile)。

### 该留多少空间

经验值是保留可用空间的 10% 到 15%。低于这个数，固态硬盘的写入性能会下降，功能更新会因为空间不足而失败，系统还原与休眠也会失效。

128 GB 的教室设备很容易踩线，这类设备建议把用户目录下的 Downloads、Videos 重定向到其他盘，路径在「设置 → 系统 → 存储 → 高级存储设置 → 新内容的保存位置」。

### 两个容易忽略的目录

* **AppData**。软件即使装在别的盘，日志与缓存通常还是写在 `C:\Users\<用户名>\AppData` 下。这部分可以用 [AppData 管理](csh://tool/appdata) 按分类查看与清理，比手动翻目录安全。
* **幽灵文件**。桌面或某个文件夹里明明没有文件，却占着空间，或者某个文件删了又重新出现。这类情况用 [幽灵文件清理](csh://tool/ghostfile) 扫一遍，它只检查指定的那一层目录，不会往下翻，所以填哪一层就清哪一层。删除是永久的，不进回收站，动手前确认目录选对。

## 三、内存与分页

### 内存压缩

Windows 11 默认开启内存压缩，把不活跃的内存页压缩后留在内存里，减少写分页文件的次数。压缩耗一点处理器，但比读写硬盘快得多。

不建议关闭。任务管理器性能页里，内存一栏会显示「已压缩」的量，几百 MB 属于正常。

### 内存不够的判断

内存是否够用，看两个数：

* **使用率长期在 85% 以上**，说明确实吃紧。
* **提交大小远大于物理内存**，说明系统已经在大量换页。

8 GB 在 Windows 11 上属于勉强够用：浏览器开十个标签、加一个 Office、再加一个教学软件，就会接近上限。4 GB 基本不够。这类设备最有效的优化是加内存条，而不是调设置。

### 什么时候需要改分页文件

绝大多数情况不需要。只有以下场景值得考虑：

* 系统盘空间极度紧张，且分页文件被撑得很大。可以把它挪到另一块物理硬盘上，但**不要**设在移动硬盘或 U 盘上，也不建议设在与系统盘同一块物理硬盘的其他分区，那样性能没有改善。
* 需要完整崩溃转储用于排查蓝屏，这种情况下要保证分页文件不小于物理内存。

改动在 [虚拟内存](csh://tool/pagefile) 里做：关掉「自动管理所有驱动器的分页文件大小」，选中目标盘，选择「自定义大小」或「无分页文件」，点「设置」确认，然后重启。

### 看进程占用

不想装任何工具时，`Ctrl + Shift + Esc` 打开任务管理器，在「进程」页按内存排序，能立刻看出谁在吃内存。展开进程可以看到同一程序下的多个子进程，浏览器这类程序通常会有十几个。

本应用内的 [Hub AI](csh://page/hubai) 也能做这件事：打开后会展示本机概况，包括内存、进程、启动项与已装软件，并给出初步判断。它需要先在 [设置 → Hub AI](csh://settings/hubai) 里配置模型。

## 四、启动项与服务

### 启动影响的分级

按 `Ctrl + Shift + Esc` 打开任务管理器，切到「启动应用」页。这里比「设置 → 应用 → 启动」多了两列关键信息：发布者与启动影响。

启动影响由系统实际测量得出，分级标准如下：

| 等级  | 判定  |
| --- | --- |
| 高   | 启动时占用处理器超过 1 秒，或磁盘读写超过 3 MB |
| 中   | 处理器占用 300 毫秒到 1 秒，或磁盘读写 292 KB 到 3 MB |
| 低   | 处理器占用低于 300 毫秒且磁盘读写低于 292 KB |
| 未测量 | 还没有采集到数据 |

右键某一项选择「禁用」即可，改动立刻生效，下次开机不再启动。想反悔随时可以重新启用，这一点与删除程序完全不同。

### 该禁的与该留的

**可以放心禁用的**：软件自动更新程序、游戏平台助手、网盘同步客户端（不用时）、各类「助手」与「加速器」、播放器后台、聊天软件的开机自启（需要时手动开）。

**建议保留的**：

* 安全软件的实时防护组件。
* 显卡、声卡、触控板与鼠标的驱动管理程序，禁了可能丢失功能（例如触控板手势、音效增强）。
* 输入法。
* 需要常驻才能工作的同步工具，例如正在使用的网盘。

**不确定的**：先看发布者是不是 Microsoft，是就留着；不是就看名字能不能对上自己装过的软件，对不上先别动，右键「搜索在线」查一下。

### 三种启动来源

只改任务管理器有时不够，因为启动项有三个存放位置：

1. **任务管理器 / 设置里的启动应用**，覆盖绝大多数正规软件。
2. **启动文件夹**。在运行框（`Win + R`）里输入 `shell:startup` 打开当前用户的启动文件夹，`shell:common startup` 打开所有用户的启动文件夹，里面的快捷方式会在登录后执行。
3. **注册表 Run 项**。路径是 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 与 `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`。这一层不建议手改，强行删除可能留下找不到路径的残项。

### 治本的做法

有些软件在任务管理器里禁用后，更新一次又会自己开回来。原因是它只改了系统里的注册，程序自身的设置没变。

治本的做法是进软件自己的设置，关掉「开机启动」或「随系统启动」这一项。常见于聊天软件、网盘客户端、游戏平台、以及各类硬件驱动面板。

### 服务与计划任务

这两处**不建议批量改动**。

* 服务（`services.msc`）里如果确实要动，先勾选「隐藏所有 Microsoft 服务」，只处理明确认得出来的第三方服务，例如某个已卸载软件残留的更新服务。把启动类型从「自动」改为「手动」，不要直接「禁用」。
* 计划任务（`taskschd.msc`）里可以关掉第三方软件的定时检查与推送任务，同样只处理认得出的。

关于服务的取舍可以记住一句话：认不出用途的，一律不动。系统更新、驱动安装、安全启动校验都依赖一批名字陌生的服务，关掉不会立刻出问题，而是在几个月后以「更新失败」的形式还回来。

## 五、电源与性能

### 电源模式

路径：设置 → 系统 → 电源和电池 → 电源模式。

三个档位的实际区别：

* **最佳能效**：压低处理器频率，续航最长，响应最慢。
* **平衡**：默认档，按负载动态调整。
* **最佳性能**：处理器倾向于保持较高频率，响应快，发热与耗电都上升。

教室设备常年插电，日常教学用平衡即可。需要跑大型课件、或者触控书写明显发涩时切到最佳性能，用完切回。

笔记本用电池时建议保持最佳能效或平衡，切到最佳性能后电池通常撑不过两节课。

### 节能模式

Windows 11 的节能模式（24H2 起台式机也能用）会降低屏幕亮度上限、限制后台活动。教室设备插电时不需要开，它会拖慢投影时的动画与书写响应。

### 屏幕与睡眠

两项时间要分开看：

* **关闭显示器**：只是关屏，不影响任务。教室设备可以设短一些，例如十分钟。
* **进入睡眠**：整机低功耗，任务暂停。设得太短会在讲课时突然睡眠，讲得太长又费电。

教室设备常见的问题是设成「从不睡眠」，整晚亮着。更好的做法是用 [自动关机](csh://tool/autoshutdown) 排一张时间表，到点关机，需要晚走时点一次「取消关机」撤回。

### 快速启动的取舍

快速启动让「关机」变成「保存内核状态后断电」，下次开机从该状态恢复，比完全冷启动快几秒。

代价有三个：

* 关机不是真正的完全重启，某些驱动问题、更新未完成的状态会延续。
* 双系统环境下会占用分区锁。
* 依赖休眠文件，前面关掉休眠后它也会一起失效。

日常使用保持默认（开启）即可。遇到「改了设置不生效」「驱动装了没反应」这类怪问题时，用「重启」而不是「关机再开」。

## 六、视觉与响应

### 动画与透明

路径：设置 → 辅助功能 → 视觉效果。

* 关闭「动画效果」会让窗口最小化、开始菜单弹出变成瞬间完成。老设备上主观感受提升明显，代价是界面少了过渡，看起来生硬。
* 关闭「透明效果」会去掉开始菜单与任务栏的毛玻璃，能省一点显卡开销，在集显设备上有意义。

### 桌面与壁纸

动态壁纸、幻灯片壁纸、第三方壁纸软件都会持续占用显卡与磁盘。教室设备建议用静态壁纸。

### 任务栏

任务栏上默认挂着几个用不到的入口：搜索框（可以只留图标）、任务视图按钮、小组件。右键任务栏 → 任务栏设置即可逐项关闭。

小组件会后台拉取资讯，教室设备建议关掉。

本应用内的 [系统优化](csh://tool/systemtweaks) 把这些开关集中在一页：任务栏靠左对齐、搜索框样式、隐藏任务视图与小组件、按钮合并方式、时钟显示秒、关闭通知中心、始终显示托盘图标、使用小图标、开始菜单不显示推荐建议等。改完点「应用更改」，每项下方都写了副作用。

### 通知

设置 → 系统 → 通知，可以整体关闭，也可以逐个应用关。

教室设备建议整体关闭通知，避免上课时弹出更新提示、软件广告、邮件预览。副作用是所有应用的通知都不再出现，包括需要留意的系统提示。

## 七、隐私与遥测

这一节的原则是**适度**：关掉没有实际用途的采集，保留影响功能的部分。

### 诊断数据

设置 → 隐私和安全性 → 诊断和反馈。

「诊断数据」分为必选与可选两档。**必选部分不能关闭**，它承载错误报告与安全相关的上报。可选部分（增强型诊断数据）可以关掉，代价是遇到问题时系统给出的建议会不那么具体。

下面的「改善墨迹书写和键入」、「量身定制的体验」可以关闭。

### 广告与推荐

Windows 11 在几处放了推荐内容：开始菜单的推荐区域、锁屏的聚焦推广、设置页的建议、以及部分应用的推广位。

这些可以在设置里逐项关闭，[系统优化](csh://tool/systemtweaks) 的「推荐内容与建议」分组已经把这几项集中起来。

### 应用权限

设置 → 隐私和安全性，可以按类别管理位置、相机、麦克风、通知、后台应用等权限。

教室设备建议关掉「后台应用」，能减少一批不用的应用在后台跑。副作用是部分需要后台刷新的应用（例如邮件）不会及时更新。

## 八、系统更新

### 不建议关闭更新

关闭 Windows 更新省下的不是性能，而是麻烦：安全补丁停更，插 U 盘的风险上升；驱动与运行库不再更新，新软件装不上；累积更新停太久，之后再想更新会因为跨度太大而失败。

合理的做法是**控制时间**，不是关闭。

### 分清两类更新

* **质量更新**：每月一次，修漏洞与小问题，体积小，装完重启一次即可。这类应当按时装。
* **功能更新**：每年一到两次，版本号会变（例如 24H2 到 25H2），体积大、耗时长。教室设备建议放到假期装，装完观察两周再批量推给其他教室。

### 暂停与延后

「设置 → Windows 更新」可以暂停更新一段时间。功能更新可以单独设置「推迟若干天」，适合不希望在学期中变动环境的教室设备。

### 驱动更新

显卡与网卡驱动优先从厂商官网或厂商工具更新，Windows 更新里的驱动版本通常偏旧。其余驱动交给系统即可。

遇到「更新后某设备不工作」的情况，在设备管理器里回滚驱动，比重新安装系统快得多。

## 九、软件与预装

### 该卸载什么

打开设置 → 应用 → 已安装的应用，按大小排序，先看占地方又不用的。教室设备上常见的冗余项：

* 多个浏览器。留一个 Edge 即可，需要兼容性时加一个 Chrome。
* 多个安全软件。同时装两个杀毒软件会互相扫描，明显拖慢速度，只留一个。
* 厂商预装的「管家」「助手」「优化」类程序，功能与本指南做的事重叠，且常驻后台。
* 从不使用的商店应用。

### 卸载的正确方式

一律从「已安装的应用」或软件自己的卸载程序卸载。不要直接用工具删安装目录，那会留下注册表残项与启动项，反而更难清理。

系统自带的组件（例如 Edge、商店、Defender）不建议强删，强删后系统更新会失败，且很难恢复。本应用把应用卸载放在 [实验性功能](csh://page/experimental) 里，就是因为它涉及系统组件，需要谨慎处理。

### 一个常见误区

「精简版系统」看起来省资源，实际代价是组件缺失导致更新失败、部分软件装不上、出问题无法用系统自带工具修复。教室设备追求的是稳定可维护，不是极限精简。

## 十、教室场景的几件具体事

### 多人使用

一台教室电脑往往有多个账户。为每位教师单独建账户，避免所有人共用一个账户：共用账户会让每个人装的软件、改的设置互相覆盖，出问题也分不清是谁改的。

### 桌面文件与 OneDrive

Windows 11 默认把桌面、文档、图片放进 OneDrive 同步。教室设备如果统一使用同一个微软账户登录，会把所有教室的文件混在一起；如果不用 OneDrive，建议在设置里取消这些目录的同步，改回本地目录。

已经开启同步的，取消时要选择「保留在本机」，否则云端一删本地也没了。

### 投影与显示

`Win + P` 切换投影模式，常用的是「复制」（两边同画面）与「扩展」（两块屏不同内容）。分辨率与缩放建议在「扩展」模式下分别设置，缩放比例不一致会导致窗口在拖动时大小跳变。

### 关机与断电

教室设备最常见的数据损失来自直接拉闸。用 [自动关机](csh://tool/autoshutdown) 定时关机后，设备会在到点前保存并关闭；如果确实需要立刻断电，先关机再断。

对电压不稳的教室，建议配一个小容量 UPS，比任何软件保护都实在。

### 系统修复

启动项、系统文件损坏、更新卡住这类问题，可以用 [系统修复](csh://tool/repair) 里的任务逐项处理，每项执行前都有说明，执行中能看到命令输出。涉及范围较大的动作会二次确认。

## 十一、做完之后怎么验证

优化完不要凭感觉判断，用数据对比：

1. **开机时间**：任务管理器 → 启动应用页，右下角有「上次 BIOS 所用时间」。改完重启两三次再看这个数。
2. **内存占用**：任务管理器 → 性能 → 内存，看空闲时的占用与「已压缩」的量。
3. **磁盘空间**：设置 → 存储，记录改动前后的可用空间。
4. **启动影响**：启动应用页里各程序的等级是否下降。

如果某一项改动之后出现了说不清的问题，按这个顺序回退：

1. 把那一处改动改回默认。
2. 用之前创建的系统还原点还原。
3. 卸载最近安装的软件或驱动。
4. 功能更新后十天内，可以在「设置 → 系统 → 恢复」里回退到上一版本。

## 十二、常见误区速查

| 做法  | 为什么不该做 |
| --- | --- |
| 关闭分页文件换性能 | 提交内存下降，大程序申请内存会失败；蓝屏拿不到转储 |
| 关闭休眠只为省空间 | 可用，但要接受快速启动、混合睡眠一起失效；也可改成精简模式 |
| 成批禁用系统服务 | 更新校验、驱动安装、安全校验依赖这些服务，故障会延后出现 |
| 关闭 Windows 安全中心 | 教室设备插 U 盘频繁，这是最后防线；应改用排除目录 |
| 用注册表清理工具 | 收益无法测量，误删后系统行为异常难以定位 |
| 内存「释放」工具 | 强行把内存写回分页文件，反而增加磁盘读写 |
| 删除 WinSxS 内容 | 组件存储被破坏，功能更新直接失败 |
| 关闭系统更新 | 安全补丁与运行库停更，之后再更新容易失败 |
| 追求「精简版系统」 | 组件缺失导致更新与修复都失效，可维护性大幅下降 |
| 装两个杀毒软件 | 互相扫描，速度明显下降，隔离区还会互相误报 |

## 可以直接用的工具

本应用内与本指南对应的入口，装好后不必再记路径与命令：

* [磁盘空间](csh://tool/disk-map)：方块图看占用，逐层展开。
* [AppData 管理](csh://tool/appdata)：按分类清理用户目录下的缓存。
* [幽灵文件清理](csh://tool/ghostfile)：处理看得见删不掉的残留文件。
* [系统优化](csh://tool/systemtweaks)：任务栏、开始菜单、推荐内容的开关集中在一页。
* [系统功能](csh://tool/sysfeatures)：休眠、电源计划、内存压缩、长路径、转储、遥测。
* [虚拟内存](csh://tool/pagefile)：分页文件的查看与调整。
* [自动关机](csh://tool/autoshutdown)：按天排时间表，到点关机。
* [系统修复](csh://tool/repair)：常见系统问题的修复任务列表。
* [Hub AI](csh://page/hubai)：看清本机的处理器、内存、磁盘、进程与启动项。
