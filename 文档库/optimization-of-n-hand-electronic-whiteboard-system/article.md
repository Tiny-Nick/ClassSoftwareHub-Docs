# N 手电子白板生存指南（一）：系统优化

每年开学前后，电教委员都要面对同一件事：换教室，接手一台 N 手的电子白板。上一届留下的系统是什么状态，基本没法预判——桌面文件堆到屏幕外，C 盘红得发紫，后台软件开机就占满内存。

这份经验面向设备为 Windows 系统的电教委员，计划分三期：系统优化、软件推荐、特定软件的使用教程。本篇是第一期，讲如何把一台陌生的白板整理到能稳定上课的状态。

作者从小学一年级开始担任电教委员，用过的系统从 Windows 2000 一直到 Windows 11 预览版，另外接触过 Ubuntu、Deepin、统信 UOS、麒麟银河，也短暂用过 macOS。下面这些做法来自实际维护经历，学校情况不同，取舍时以本校设备和老师的使用习惯为准。

## 一、掌握设备基本信息

管理一台要用满两个学期的白板，第一步是了解它的底子。触控屏没有鼠标右键，长按任务栏上的开始图标，选择「系统」，就能看到处理器、显卡、硬盘、内存以及系统版本等信息。

这些信息有两个用途：判断性能余量，以及核对软件层面的安装是否合理。多数学校的白板运行 Windows 7 或 Windows 10，也有不少已经装到 Windows 11。厂商与学校预装系统时通常会匹配设备性能，这一项不必过度操心。

如果需要提出系统升级建议，可以参考以下经验：

- 英特尔 7 代及以上的处理器，可以尝试 Windows 10。界面更现代，老师也更熟悉，触控体验相对完善。
- Windows 7 的触控在部分场景下并不好用。例如在 Word 文档里上下滑动页面，会变成选择文字，只能拖动右侧滚动条；Windows 10 与 Windows 11 没有这个问题。
- 升级前先征得学校和班主任同意，确认设备性能匹配，并确保自己有把握完成安装与回退。

## 二、优化存储空间

教室白板最普遍的毛病是磁盘空间。C 盘长期处于红色状态，文件路径像老小区的电箱电线一样缠在一起，文件夹套文件夹，整理时很容易让人血压升高。

### 系统自带清理

先打开 C 盘根目录：

- Windows 7 / Windows 10：在文件资源管理器上方找到驱动器工具，点击「清理」。
- Windows 11：点击上方快捷操作栏的三个点，在下拉菜单里找到「清理」。

进入清理工具后，再点一次「清理系统文件」。这一步会调用系统自带的清理组件，清掉系统自身不再需要的内容。长期没有清理过的设备，一次清出五六个 GB 属于正常范围，让它自己跑完即可。

### 第三方工具组合

系统清理之后，可以按下面的顺序补一轮：

1. 使用电脑自带杀毒软件的清理工具，例如火绒安全软件的常规清理。
2. 安装微软电脑管家，再用它的清理工具清理一次。
3. 安装 Dism++，使用其中的「空间回收」，清理更深层的系统垃圾。

微软电脑管家值得单独说明。用 SpaceSniffer 扫描 C 盘可以看到，除 Windows 文件夹外，占用最大的是 `AppData`。很多软件即使安装在其他分区，出于数据安全考虑，日志与缓存仍会写入 C 盘的用户目录。市面上不少杀毒软件的清理工具没有针对这一目录做适配，微软电脑管家做了，清理效果会明显一些。作者第一次使用时，微软电脑管家从 C 盘清理出约 25 GB 空间。

一套组合下来，一台长期未清理的电脑通常能释放 20 GB 左右。这个思路同样适用于普通家用电脑。

### 手动清理缓存

微软电脑管家也不是万能的，部分缓存需要手动处理：

- QQ、微信：进入「设置 → 存储管理」，清理聊天缓存。
- 希沃白板 5：进入 `AppData` 目录查看 `Seewo` 文件夹，占用可能超过 10 GB。里面的文件夹以手机号命名，保存的是每位登录过的教师的用户信息。教室设备基本不会用到这些信息，建议先卸载希沃白板 5，再打开 `Seewo` 文件夹，全选内容后按 `Shift + Delete` 永久删除。保留 `Seewo` 这个空文件夹本身，不要连文件夹一起删，最后到希沃官网重新下载安装。

> 删除前确认本班正在使用的课件已经备份，避免误删上一届留下的、仍要参考的资料。

最后清理上一届留下的课件。这一步做完，存储空间通常就回到可用状态。

## 三、优化内存占用

学校白板常见配置是 4 GB 或 8 GB 内存，后台软件一多就吃紧。这一节推荐内存清理工具 Mem Reduct。

Mem Reduct 免费开源，能把占用压下来：作者在 Windows 11 上同时开着多个后台软件和大量浏览器标签页，内存占用约 9 GB，使用后降到 4 GB。这类工具不只电教委员能用，普通办公场景同样适用。

下载时建议直接去 GitHub 的官方仓库。作者用 Bing 搜索时遇到过伪装成下载页的银狐木马，百度搜索结果前几条多为广告，容易下载到非官方版本。

## 四、基本软件管理

卸载用不到的软件，本身就是系统优化。教学场景不需要游戏模拟器，也不需要同时装五六个浏览器。

### 浏览器

曾在一间教室的电脑上见到 360 安全浏览器、360 极速浏览器、Google Chrome、Firefox、Microsoft Edge、夸克浏览器、联想浏览器、希沃浏览器，甚至豆包。浏览器留一个就够：

- 系统内置的 Edge 已经够用。
- 习惯上可以保留 Chrome 与 Edge 两个。
- Windows 7 设备装不了新版浏览器时，可以改用 360 极速浏览器，广告相对少一些。

### Office

- 有条件时首选 Microsoft 365。
- 退一步安装 Office 2016。
- 再装一个 WPS 作为备用。

WPS 在触控场景下的体验一般，PPT 批注画出来的线条不够顺滑。Office 的触控优化更好，无广告、启动快、占用低、界面简洁，问题也少。部分老师依赖 WPS 的模板，这种情况下保留 WPS 即可。

### 其他软件

- 通讯：QQ、钉钉、微信。
- 有直播需求时保留腾讯会议。
- 杀毒软件保留一个火绒，功能齐全、没有广告，右键菜单与开机启动项也方便管理。
- 学校内部软件按需保留。
- 系统自带的媒体播放器、照片、截图工具、Microsoft Store 可以保留；OneDrive、反馈中心这类用不到的应用可以直接卸载。

按这个范围整理后，基本能覆盖教学场景 95% 的需求。

## 五、系统设置管理

### 电源模式

Windows 提供节能、平衡、高性能三档电源模式。日常教学用平衡即可；高性能会让处理器以更高的电压和频率运行，温度上升，白板 OPS 模块的散热压力也随之变大。

作者的习惯是按使用场景切换：

- 午休、大课间、晚自习等空闲时段，使用平衡模式。
- 上课教学期间切到高性能，保证操作流畅。

网上常说平衡与高性能差别不大，但实际使用中仍有差距。作者在平衡模式下运行 Minecraft 只能跑到 70 帧，高性能模式下可以到 260 帧。

### 触控辅助

在任务栏设置中打开虚拟键盘与虚拟触控板：

- 虚拟键盘方便输入文字。
- 虚拟触控板可以模拟笔记本电脑的触控板，适合需要精确指针的场景，也适合没有适配触控的软件与网站。

### 系统更新

教学设备不必追着 Windows 更新跑。设备上有第三方杀毒软件保障安全，当前版本没有重大问题时，可以暂时跳过功能更新，把时间留给教学。
